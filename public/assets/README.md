# 图片素材放置说明

这个目录已经按网页栏目分好。你只需要把图片改成下面约定的文件名，再拖进对应文件夹；不需要修改代码。

## 1. 精选案例封面

放入 `projects` 文件夹：

- `01-yangming.jpg`：余姚阳明温泉山庄
- `02-yuelongwan.jpg`：余姚悦龙湾
- `03-qidu.jpg`：温州七都华侨花园
- `04-binrongfu.jpg`：杭州滨融府
- `05-daye.jpg`：大冶芳香产业文化展馆
- `06-small-ideas.jpg`：方案中的小想法

建议使用竖图，比例约为 4:5，长边 1800–2400 像素。

## 2. 摄影

摄影照片使用两位数连续命名：`01.jpg`、`02.jpg`、`03.jpg`……

- `gallery/photography/street`：街头摄影，01–23
- `gallery/photography/landscape`：风光摄影，01–13
- `gallery/photography/interior`：室内摄影，01–04
- `gallery/photography/film`：胶片摄影，01–14

横图、竖图、方图都可以，网页会按现有瀑布流比例自动裁切。

## 3. 手作、插花与房间改造

- `gallery/craft`：手作，01–08
- `gallery/ikebana`：插花，01–10
- `gallery/room/before.jpg`：房间改造前
- `gallery/room/after.jpg`：房间改造后
- `gallery/room/01.jpg`、`02.jpg`：房间细节

## 4. 方案中的小想法

放入 `small-ideas` 文件夹：`01.jpg`、`02.jpg`、`03.jpg`。

## 最简单的操作方法

1. 在 Windows 文件资源管理器中打开本项目的 `public/assets` 文件夹。
2. 按上面的分类进入对应子文件夹。
3. 把原图复制进去，并严格改成约定文件名。文件扩展名统一使用 `.jpg`。
4. 回到 Codex，直接说：“我已经放好图片，请检查并发布网站。”

如果照片数量不足，可以只放已有的文件；没有对应文件的位置会继续显示占位色块，不会出现破图图标。
